# Projeto-FrontWeb

Uma interface web moderna e responsiva para um Sistema de Vendas, visualização de catálogo de produtos e gerenciamento de carrinho de compras e gestão de estoque. Focada em uma experiência de usuário fluida e componentização limpa.


🛠️ Tecnologias<br>

•	React — Biblioteca para construção de interfaces de usuário dinâmicas.<br>
•	JavaScript (ES6+) — Linguagem base para a lógica da aplicação.<br>
•	HTML5 & CSS3 — Estrutura e estilização base da web.<br>
•	Tailwind CSS — Framework CSS utilitário para design rápido e responsivo.<br>
•	React Icons — Biblioteca centralizada de ícones para o ecossistema React.<br>

🛠️ Recursos Planejados<br>

•	Carrinho de Compras: Adicionar, remover e alterar a quantidade de itens, com cálculo automático do total.<br>
•	Página de Detalhes: Visualização expandida das informações e especificações de um produto.<br>
• Filtros e Busca: Busca por texto e filtragem de produtos por categoria ou preço.<br>
•	Dashboard Comercial: Painel com indicadores de faturamento e vendas.<br>
•	Controle de Estoque: Listagem, cadastro e edição de mercadorias.<br>
•	Interface Responsiva: Design otimizado para computadores, tablets e celulares.<br>
